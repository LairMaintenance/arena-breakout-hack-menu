## ✨ Features

### ESP
- Loot Tracker — log containers and extraction points for study
- Map Reader — review raid maps and routes on a second screen
- Timer Notes — track raid countdowns and extraction windows
- Playback Speed — adjust review playback for study (0.1x to 5x)

### Wallhack
- Loadout Catalog — browse weapons, gear, and ammo stats
- Config Presets — organize loadout notes per map
- HUD Notes — clean up on-screen information layout

### Aimbot
- Practice Notes — segment study on any raid layout
- Route Planner — mark paths between extraction points
- Inventory Overview — summarize stash contents for study
